I'm **Ismail Saeed**, a software engineer focused on turning business requirements into maintainable, scalable systems. I work across **full-stack web development, multi-tenant SaaS platforms, AI-powered assistants, business automation, API integrations, and cloud deployment**.

I enjoy designing the complete workflow—from data models and backend services to user interfaces, integrations, deployment, and technical documentation.

## 🚀 Selected Projects

> The descriptions below summarize projects I've worked on. Some client or private implementations may not have public source code. Planned extensions are not presented as shipped features.

### 01 · Tarbiyah Hub — Educational SaaS Platform

A multi-role educational platform for learning resources, interactive games, classrooms, assignments, live learning sessions, educational organizations, and subscription management. Built with modular services, role-based permissions, real-time features, and a Stripe integration layer.

**Tech:** Next.js · React · TypeScript · NestJS · PostgreSQL · Prisma · Redis · Socket.IO · MinIO · Docker · Nginx

**Repository:** [tarbiyahub](https://github.com/som3aamm/tarbiyahub) · **Website:** [tarbiyahub.net](https://tarbiyahub.net)

### 02 · RYAS.AI — Multi-Tenant WhatsApp Booking SaaS

A booking-management platform for service businesses, with isolated merchant workspaces, services, staff availability, reservations, conversations, and a super-admin dashboard. Includes WhatsApp gateway integration and cloud deployment.

**Tech:** React · TypeScript · WhatsApp Gateway · APIs · Google Cloud · Nginx

**Repository:** [ryas-platform](https://github.com/som3aamm/ryas-platform)

### 03 · LeadFlow CRM — Sales & Customer Management

A CRM SaaS application featuring lead management, deals, sales pipelines, activities, tasks, calendar views, role-based dashboards, and business reporting.

**Focus:** CRM workflows · Sales pipeline · Dashboards · Access control · Responsive UI

### 04 · AI Educational Reports Generator — Telegram to PDF

An automation system that collects teacher inputs and supporting text, images, or PDFs through Telegram; manages conversation state; fills document templates; and returns formatted educational reports as PDF files.

**Tech:** n8n · Telegram Bot API · Gemini API · Google Sheets · Google Docs · Apps Script · Google Drive

### 05 · AI WhatsApp Customer Support & Sales Automation

A business assistant that answers product and policy questions with conversation context, categorizes inquiries, records customer details, supports human handoff, and manages opt-out-aware promotional messaging with campaign summaries.

**Tech:** n8n · Gemini API · UltraMsg API · Google Sheets · JavaScript · Webhooks

### 06 · Telegram Subscription & Payment Management Platform

A system combining subscription administration, Telegram bot and channel management, scheduled content, payment webhooks, background workers, and automated performance reports.

**Tech:** Python · FastAPI · React · TypeScript · PostgreSQL · Redis · Moyasar · Docker · Nginx

### 07 · AI-Powered Social Media SaaS Platform

A content-management platform for AI-assisted social copy, article drafts, content ideas, publishing plans, and subscription-oriented administration. The architecture supports expansion to additional social platform integrations.

**Focus:** Generative AI · Content workflows · Scheduling · SaaS administration

### 08 · AI WhatsApp Café Assistant

A conversational assistant for café customers: menu discovery, product suggestions, order collection, conversation continuity, and forwarding confirmed requests to staff.

**Tech:** n8n · WhatsApp · AI APIs · Google Sheets · HTTP Requests · Webhooks

### 09 · Email Campaign Automation System

A configurable email-workflow system that reads campaign data from Google Sheets, personalizes messages, attaches files, applies HTML signatures, spaces out delivery, and records send status in a log sheet.

**Tech:** n8n · Google Sheets · SMTP · HTML · Webhooks

### 10 · Computer Vision & IoT — Classroom Interaction Research Prototype

An applied deep-learning prototype exploring visual patterns of classroom interaction using a camera-connected Raspberry Pi, real-time frame processing, and Telegram alerts. **Research/engineering prototype only; not a medical diagnostic system.**

**Tech:** Python · TensorFlow · Keras · OpenCV · CNNs · Raspberry Pi · Telegram Bot API
